# Code of Conduct

Aurora has adopted the **Contributor Covenant, version 2.1** as its Code of Conduct. The full canonical text is maintained upstream and applies to all Aurora project spaces, including this repository, the discussions board, issue tracker, and any community channels.

**Full text:** [https://www.contributor-covenant.org/version/2/1/code_of_conduct/](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)

**Plain-text version:** [https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt](https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt)

## Short Summary

Be kind. Be specific. Assume good faith. Disagreement is welcome; disrespect is not. Focus on the work — datasets, code, methods, evidence — not on the people.

## Scope

This Code of Conduct applies anywhere the Aurora project operates: GitHub issues, pull requests, discussions, comments on commits, the official Discord (when launched), the FantasyLab.ai community channels, and any in-person or virtual event organised under the Aurora name.

It applies equally to all contributors, maintainers, sponsors, and users.

## Reporting

If you experience or witness behaviour that violates this Code of Conduct, please report it privately to the project maintainer:

📧 **conduct@fantasylab.ai**

All reports are handled confidentially. We do not publicly identify reporters. Reports are reviewed within 72 hours; investigation timing depends on complexity.

## Enforcement

The maintainers follow the enforcement ladder defined in the Contributor Covenant v2.1: correction → warning → temporary ban → permanent ban. The specific response is proportional to the severity, pattern, and impact of the behaviour.

Maintainers who do not follow or enforce the Code of Conduct in good faith may face temporary or permanent repercussions as determined by other members of the project's leadership.
