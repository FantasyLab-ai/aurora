how to read this graph
GRAPH — entities are nodes (sized by role: forcing/state/response). Edges are causal/relational links. Mint = anchored from a known prior, amber = discovered, red = data deviates from template, faded = template-only.
SPACETIME — each row is one entity's worldline (past, to the left of NOW) and probability cone (future, to the right). Lighter / wider = more uncertain.
PHASE SPACE — project two most-variable entities onto a plane. Dashed ellipses are attractors (steady regimes), the line between them is the bifurcation manifold (where regimes flip), the trail is the system's history.
INSPECT / INTERVENE / SIMULATE — read mode, perturb a node and propagate Δ through edges, or run validated dynamics forward as a new cone.
Confidence — red <30% mostly inferred, amber 30-60% partial, green ≥60% strongly anchored.
